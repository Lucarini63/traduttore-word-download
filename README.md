# Traduttore Word Multilingue Professionale

Programma per Windows per la **traduzione di documenti Word in più lingue**.

## Download

Scarica l'ultima versione dell'installer:

**[Setup_TraduttoreWordMultilingueProfessionale.exe](https://github.com/Lucarini63/traduttore-word-download/releases/latest/download/Setup_TraduttoreWordMultilingueProfessionale.exe)**

Tutte le versioni sono disponibili nella pagina [Releases](https://github.com/Lucarini63/traduttore-word-download/releases).

## Requisiti

- Windows 10 o Windows 11

## Installazione

1. Scarica il file `Setup_TraduttoreWordMultilingueProfessionale.exe`.
2. Avvia il file e segui la procedura guidata.
3. Se Windows mostra l'avviso SmartScreen, seleziona **Ulteriori informazioni** e poi **Esegui comunque**.
